# NEBULA Complete Installation Guide

## System Requirements

### Hardware Requirements
**Minimum:**
- GPU: NVIDIA RTX 3070 Ti (12GB VRAM)
- CPU: Intel i7-10700K or AMD Ryzen 7 3700X
- RAM: 32GB DDR4 3200MHz
- Storage: 500GB NVMe SSD (PCIe 3.0)
- Windows 11 Pro 64-bit

**Recommended:**
- GPU: NVIDIA RTX 4090 (24GB VRAM)
- CPU: Intel i9-13900K or AMD Ryzen 9 7950X
- RAM: 64GB DDR5 5600MHz
- Storage: 2TB NVMe SSD (PCIe 4.0)

## Step 5: Configure CUDA Compilation

### 5.1 Create Custom Build Rules
Create `Source\NEBULA\NEBULA.CUDA.Build.cs`:
```csharp
using System.IO;
using UnrealBuildTool;

public class NEBULACUDABuildRules
{
    public static void CompileCUDAFiles(ModuleRules Rules, ReadOnlyTargetRules Target)
    {
        string CUDAPath = "C:/Program Files/NVIDIA GPU Computing Toolkit/CUDA/v12.3";
        string nvccPath = Path.Combine(CUDAPath, "bin/nvcc.exe");
        
        string[] CUDAFiles = Directory.GetFiles(
            Path.Combine(Rules.ModuleDirectory, "Private"), 
            "*.cu"
        );
        
        foreach (string CUDAFile in CUDAFiles)
        {
            string OutputFile = Path.ChangeExtension(CUDAFile, ".obj");
            
            string Arguments = string.Format(
                "-c \"{0}\" -o \"{1}\" -arch=sm_86 -O3 --use_fast_math",
                CUDAFile, OutputFile
            );
            
            System.Diagnostics.Process.Start(nvccPath, Arguments).WaitForExit();
            Rules.PublicAdditionalLibraries.Add(OutputFile);
        }
    }
}
```

   - Set "Default RHI" to "DirectX 12"

## Step 9: Troubleshooting

### Common Issues and Solutions

**Issue 1: CUDA out of memory**
```powershell
# Reduce neuron count in Config/DefaultEngine.ini
[NEBULA.Settings]
DefaultNeuronCount=100000
```

**Issue 2: Shader compilation errors**
```powershell
# Clear shader cache
Remove-Item -Recurse "C:\NEBULA_PROJECT\Intermediate\ShaderCache"
Remove-Item -Recurse "C:\NEBULA_PROJECT\Saved\ShaderCache"
```

**Issue 3: OptiX not found**
```powershell
# Add to system PATH
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\ProgramData\NVIDIA Corporation\OptiX SDK 8.0.0\bin", [EnvironmentVariableTarget]::Machine)
```
